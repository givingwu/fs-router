# 贡献指南

欢迎中文或英文的复现、试用反馈、文档和代码贡献。先从一个可验证的小问题开始，无需承诺长期维护。

## 贡献方式

- [开发环境搭建](./development.md) - 设置本地开发环境
- [发布流程](./release.md) - 了解项目发布流程
- [入门贡献任务](./first-contribution.md) - 两个来自真实源码与示例的小任务，含验收标准
- [治理](https://github.com/givingwu/fs-router/blob/main/GOVERNANCE.md)、[支持](https://github.com/givingwu/fs-router/blob/main/SUPPORT.md)、[行为准则](https://github.com/givingwu/fs-router/blob/main/CODE_OF_CONDUCT.md)和[路线图](https://github.com/givingwu/fs-router/blob/main/ROADMAP.md)
- [演示与介绍草稿](./communication.md)、[采用计划](./adoption.md) - 可复现试用、真实反馈与待决定事项

## 如何贡献

1. **报告问题** - 在 [GitHub Issues](https://github.com/givingwu/fs-router/issues) 中报告 bug
2. **功能建议** - 提出新功能的想法和建议
3. **代码贡献** - 提交 Pull Request 修复问题或添加功能
4. **文档改进** - 帮助改进文档内容

## 开发指南

详细的开发环境搭建和开发流程请查看 [开发文档](./development.md)。

[完整贡献流程](https://github.com/givingwu/fs-router/blob/main/CONTRIBUTING.md)包括 fork、分支、检查、PR 和公开内容要求。Bug/feature 使用 [Issue forms](https://github.com/givingwu/fs-router/issues/new/choose)，提问和试用失败可开 blank issue。漏洞先读 [SECURITY.md](https://github.com/givingwu/fs-router/blob/main/SECURITY.md)，不要公开利用细节。
