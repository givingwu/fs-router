# 路由生成

构建器启动时扫描约定文件，生成普通 `RouteObject[]` 的 `routes` 导出和导航声明。没有虚拟路由入口需要应用导入。

## 输出文件

默认 `src/routes.tsx` 和 `src/routes-type.ts` 必须在扫描目录 `src/routes` 外。输出可能包含本机路径，请重新生成而非跨机器复制。库写入前检查路径，用临时文件替换；这不是恶意并发文件系统修改的隔离沙箱。

输出导入了根布局、页面/布局数据模块与组件。`splitting: true` 只影响非根组件；不会把 loader 从客户端 bundle 分离。

## 失败和恢复

目录不存在、根布局缺失、重复约定文件、重复 route id 和等价终端路径会使构建报告错误。隐藏目录、符号链接和 `node_modules` 不扫描。路径规则见[文件约定](../basic/file-based-routing.md)。

开发时使用宿主构建器监听；增删路由重新生成，内容未变则不写文件。修正缺失布局或冲突文件后可继续编译。连续编辑中可能出现短暂诊断，应以最终成功编译和实际页面为准。Vite 结构变化可能整页刷新。

## 自定义范围

可更改扫描/输出路径、扩展名和别名，见[插件配置](./plugin-options.md)。本库没有公开自定义生成器、路由 wrapper、元数据配置合并或预加载调度 API；需要额外路由属性时由应用明确组合生成的路由表并自行验证。
