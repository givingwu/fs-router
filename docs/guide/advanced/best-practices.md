# 使用建议

把约定文件放在 `src/routes`，可复用组件放在 `src/components`。根布局使用 `Outlet`，不要手动编辑生成路由文件。

## 保持构建可复现

固定依赖与锁文件，先生成路由再执行严格类型检查。开发、生产使用相同插件配置。生成文件可能含本机路径，建议忽略并在每台机器重新生成。

## 明确数据和错误边界

通常每个页面使用一个 `.data.ts`，复杂数据逻辑移到应用模块。浏览器模块不应含服务端密钥。使用 `error.tsx` 显示可理解的错误，用 Router pending 状态表示数据等待。

## 渐进接入

先在独立分支运行[最小示例](../../examples/index.md)，再迁入少量路由，验证深链接、404、前进后退、loader/action 和实际部署回退规则。迁移与性能判断见[迁移指南](../migration/index.md)、[性能问题](../faq/performance.md)。
