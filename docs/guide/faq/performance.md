# 性能问题

本项目没有公开竞品性能基准，不声称比其他路由库更快。

## 分包意味着什么

`@loadable/component` 默认延迟加载非根组件。根布局、loader 和它们引用的依赖仍在初始模块图内；因此大数据模块不会仅因配置 splitting 而延迟下载。关闭 splitting 可作为对照，但最终体积和网络行为受构建器优化影响。

## 如何测量

对同一应用、锁文件和路由数据分别构建 splitting 开关版本，用浏览器 Network 检查初始资源与导航时新增请求。记录压缩传输量、冷缓存/热缓存、设备和网络条件，再决定是否调整页面边界。使用生产 preview，而不是把 dev 请求量当作用户性能。

最小示例及消费者检查证明会生成多个 chunk，浏览器检查验证首次进入动态页时请求对应 chunk；这不是加载速度基准。loader 的业务耗时、缓存与请求取消由应用负责，见[数据获取](../advanced/data-fetch.md)。
